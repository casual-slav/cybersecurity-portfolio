# 📘 Playbooks

Step-by-step workflows I follow when responding to security incidents.

In a SOC, the same types of incident come up again and again: phishing emails, compromised accounts, malware alerts, risky sign-ins. Playbooks turn each one into a repeatable process, so every incident is handled consistently and nothing important gets missed, even under pressure.

Each playbook covers how to triage the alert, what to investigate and where to find the evidence, how to contain and remediate the threat, and what to record afterwards. They're based on how I work day to day and are refined as I learn from new cases.
